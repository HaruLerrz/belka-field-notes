# Public Scope

本資料夾是一份 repo-safe 公開原型，用來呈現 Issue Trace 的系統設計、資料流與部分工程判斷。

## What Is Included

| 類型 | 內容 |
|---|---|
| 架構文件 | 系統元件、資料歸屬與狀態流程 |
| 流程文件 | 投稿、來源搜尋、source map、AI 草稿與來源驗證 |
| 版本整理 | 主要版本脈絡與重要修正 |
| 範例資料 | 投稿、source map、文章 metadata、環境設定範例，以及公開首頁、投稿頁與文章頁截圖 |
| 程式片段 | 經過改寫的獨立範例，用來展示判斷邏輯 |

## What Is Kept Private

正式站使用的完整應用程式、設定、資料、prompt、log、操作紀錄與營運細節不放入公開 repo。

## Why This Is a Public Version

這個專案會接收公開投稿，也會呼叫外部搜尋與 AI API。公開 repo 的目的，是展示我如何拆解公共議題查證流程、設計來源追蹤與發布判斷，而不是散布可直接對應正式站的完整程式。
