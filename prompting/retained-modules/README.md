# Retained Prompt Modules

[返回 Prompting / Structured Writing](../README.md)

本頁整理兩組未公開完整 prompt 的語氣模組。

這兩個模組都源自前期對語氣結構、對話節奏與模型行為的整理，但用途不同：

* **京都腔語氣模組**：控制輸出風格，以高度禮貌、過度自責與邏輯反轉形成反諷。
* **低溫剝皮語氣模組**：分析對話結構，處理語意跳接、稻草人論述、預設劇本與對話投射。

完整 prompt、句式庫與判斷規則不公開；本頁保留用途、設計方向、版本演進、可公開的結構說明與輸出示範。

## 京都腔語氣模組

**開發期間：** 2025-04-19～2025-04-21  
**版本：** v1.6／v1.7  
**語言：** 繁體中文／日文  
**公開狀態：** 公開設計摘要與輸出示範；完整 prompt 保留

### Purpose

此模組用來產生一種極度禮貌、表面感謝、實際透過事實排列與邏輯反轉形成壓力的寫作方式。

方言轉換只是這個模組的表層形式；實際運作會把幾種寫作動作組合成固定結構：

* 先以感謝或自我反省降低正面衝突
* 再把時間、次數、前後差異與對方原話逐一列出
* 將責任指向包裝成自己的理解不足
* 對最低限度的回覆給予過度讚賞
* 以未來仍會繼續努力、等待或配合的方式收束

### Version Lineage

#### v1.6：核心語法

v1.6 建立主要寫作框架，包括：

* 將前後不一致稱為「靈活應對」
* 明列等待時間與聯絡次數後再過度感謝
* 把對方言行矛盾轉成自己的理解不足
* 對最低限度的回覆給予過度讚賞
* 用自責與反省包裝責任指向
* 以「感謝 → 反省 → 未來使命」收束文章

#### v1.7：邏輯反轉補丁

v1.7 主要增加：

* 邏輯反轉
* 歷史雙標對照
* 沉默與切割行為的反諷性讚美
* 不使用明顯轉折詞的婉轉構文
* 針對政黨、企業與組織發言的特殊處理

### Design Notes

這個模組的重點在於：

* 不直接使用辱罵或勝負語言
* 不替對方補充不存在的善意
* 讓事實排列本身形成壓力
* 把反諷藏在過度禮貌與過度理解中
* 維持表面合作語氣，同時保留清楚的責任指向

### Retained Scope

未公開內容包含：

* 完整 prompt
* 中文與日文句式庫
* 觸發條件
* 不同對象的專用補丁
* 版本間的完整差異

### Demo

2026 年 6 月，我以一則公共運輸事件的社群留言作為測試案例，要求模組先排除善意、資訊型與無實質內容的留言，再針對轉移焦點或具有明顯敵意的回覆，產生個別回應與長篇統整文章。

## 低溫剝皮語氣模組

**開發期間：** 2025-04-21～2025-05-22  
**版本演進：** v1.0 → v2.4.4 → v2.4.5 → v2.4.5.4  
**公開狀態：** 公開設計摘要與輸出示範；完整 prompt 保留

### Purpose

此模組用於處理對話中的語意跳接、稻草人論述、預設動機、語境偏移與自我投射。

把話說得更兇並非這個模組的目的。它的核心工作是找出：

* 對方實際回應了什麼
* 原始問題真正問了什麼
* 兩者之間在哪裡發生偏移
* 對方是否正在回應自己預設的立場
* 對話是否仍有必要繼續

### Core Principles

* 不直接使用攻擊或勝負語言
* 只指出回應內容與原始文本之間的落差
* 不替不存在的立場辯護
* 拆除對方預先安排的辯論劇本
* 以鏡像方式指出對方正在回應自己想像中的對手
* 當對話無法回到原始脈絡時，允許終止互動

### Version Lineage

#### v1.0：基礎結構

早期版本主要處理：

* 語意跳接
* 稻草人論述
* 對原文未提出內容的反駁
* 預設動機與預設立場

#### v2.4.4：對話投射與劇本辨識

後續加入：

* 對話投射辨識
* 預設劇本拆解
* 回應對象錯位
* 原始問題與回應落點比對

#### v2.4.5：語境偏移檢測

增加：

* 語境落點偏移
* 抽象化或哲學化語句迴避具體事件
* 對話是否仍在處理原始問題的判定

#### v2.4.5.4：收束與終止條件

補強：

* 結語自爆提示
* 劇本鏡像
* 語境終止型收束
* 對話無法回歸原始脈絡時的退出規則

### Design Notes

這個模組重視對話結構，表面語氣只作為輔助線索。

它嘗試避免以下情況：

* 被迫替自己沒有說過的立場辯護
* 進入對方預設好的辯論框架
* 讓抽象或情緒化語言遮蔽具體問題
* 在對話已經失去共同語境後繼續消耗

### Retained Scope

未公開內容包含：

* 完整 prompt
* 判斷規則
* 句式庫
* 劇本鏡像模板
* 終止條件細節
* 版本間完整差異

### Demo

2026 年 6 月，我以一篇長文回覆及一串多輪留言作為測試案例，呈現模組如何保留真正存在的不同意見，同時辨識外加指控、對象錯置、語境偏移與連續換題。

兩個案例分別展示：

* 將其他人物與整個政治群體的言論集中掛到作者身上的長文回覆。
* 每當原命題受到檢驗，便將題目移往監所空間、整體統計、歷史背景與宣傳感受的多輪留言。

## Why the Full Prompts Are Retained

我仍認同公開分享的價值，但這兩個模組的完整 prompt 目前保留，因為其中已包含：

* 大量句式庫
* 特定任務的判斷流程
* 可直接重複使用的寫作模板
* 多次修正後的版本差異
* 對特定對話場景的操作細節

公開 repo 主要記錄設計能力、開發歷程與模組結構；完整原文仍保留在個人資料中。

## Relationship to Public Modules

```text
GPT 語言去魅對照表
        ↓
語氣結構辨識與依附風險提示模組
        ↓
從語氣辨識延伸至語氣控制與對話反制
        ↓
京都腔語氣模組／低溫剝皮語氣模組
```

公開模組主要處理：

* 語氣風險辨識
* 模型自我檢查
* 語言透明化

保留模組則進一步處理：

* 特定風格生成
* 對話結構拆解
* 反諷寫作
* 語境偏移與劇本投射
