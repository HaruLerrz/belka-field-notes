# Public Issue Writing

本頁整理我在 Threads 與 Facebook 撰寫的部分公共議題文章，內容涵蓋技術政策、法律程序、國會制度、憲政權限與矯正制度。

這些文章通常起於社群上正在流通的說法、制度爭議或讀者疑問。我會先確認原始命題，再查找法規、判決、政府資料、制度背景與相關報導，最後依平台閱讀習慣整理成問答、條列、時間線或長文。

## Working Method

```text
確認原始問題與爭議命題
        ↓
區分事實、法規、程序與立場判斷
        ↓
查找原始資料與可信來源
        ↓
比對不同版本、年份與適用範圍
        ↓
決定問答、條列、時間線或長文形式
        ↓
標示爭議點、限制與仍待確認的部分
        ↓
依留言中的新問題補充或修正
```

整理過程中特別注意：

* 不把不同案件、法條或程序合併成同一命題。
* 區分「判決已定讞」與「判決形成過程仍有爭議」。
* 區分法律條文、法院見解、政治主張與個人評論。
* 交代制度適用的時間點，避免用後來的法規回推早期事件。
* 保留原始資料連結，方便讀者自行核對。
* 留言出現新的命題時，先判斷它是否仍在原文討論範圍內。

## Formats Used

不同議題會使用不同形式：

| 形式 | 適用情境 |
|---|---|
| Q&A | 法律程序、技術名詞與常見疑問 |
| 條文比較 | 草案版本、權限差異與制度效果 |
| 時間線 | 法規施行、案件進度與程序變化 |
| 長文 | 需要同時處理背景、反論與多個爭點 |
| 留言補充 | 原文發布後出現的新問題或命題偏移 |
| 生活化說明 | 制度內容需要降低閱讀門檻時 |

## Revision and Comment Handling

公共議題文章發布後，留言常會帶入新的案件、立場或假設。後續回應通常依以下順序處理：

1. 重述原文真正提出的命題。
2. 指出留言新增或替換了哪些前提。
3. 回到法規、資料或程序本身。
4. 補充原文篇幅未能處理的內容。
5. 必要時標明討論範圍，避免議題持續漂移。

部分文章帶有明確政治立場；資料整理、法律程序與個人評論仍分開呈現，讓讀者可以辨認各段內容的性質。
